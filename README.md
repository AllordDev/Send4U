## 🌟 نظرة عامة | Overview

**Send4U** هو تطبيق أندرويد عصري فائق السرعة مصمم لنقل الملفات، المجلدات، التطبيقات، وجهات الاتصال محلياً عبر شبكات **Wi-Fi / Hotspot (2.4GHz & 5GHz)** دون الحاجة لاتصال بالإنترنت أو كابلات أو خوادم سحابية.

يعتمد التطبيق على معمارية **Zero-Cache Direct Streaming** التي تضمن نقل البيانات وتدفقها مباشرة بأقصى سرعة ممكنة دون استهلاك مضاعف للذاكرة المؤقتة، إلى جانب **بوابة ويب متكاملة (Zero-Install Web Portal)** تحول هاتفك إلى خادم محلي يتيح لأي جهاز (Windows, Mac, iOS, iPadOS) مشاركة الملفات، المحادثة الصوتية، استخدام السبورة التفاعلية، ومعالجة مستندات PDF مباشرة عبر المتصفح.

**Send4U** is a high-performance offline peer-to-peer file and app transfer suite for Android, engineered with Kotlin and Jetpack Compose (Material 3). Utilizing a **Zero-Cache Streaming** architecture, it transfers files, directories, split APKs, and contacts over local **Wi-Fi / Hotspot (2.4GHz & 5GHz)** with zero storage bloat, real-time **AES-256 CTR** stream encryption, and a full-featured **Zero-Install Web Portal** for seamless cross-platform collaboration.

## 🚀 أبرز المميزات | Key Features

### 1. تجربة مستخدم متخصصة وكشف ذكي لعتاد 5GHz | Dedicated Interfaces & 5GHz Hardware Detection
- **واجهات عمل مستقلة:** تصميم واضح ومقسم بدقة لكل مهمة: **إرسال (Send)**، **استلام (Receive)**، **مشاركة الويب (Web Share)**، **غرفة المحادثة (Chat)**، و**استوديو الأدوات الإضافية (Extra Features)**.
- **فحص تلقائي لدعم 5GHz:** يكتشف التطبيق قدرات بطاقة الشبكة في هاتفك تلقائياً لتفعيل النقل عبر تردد **5GHz فائق السرعة (يصل إلى +80 MB/s)**، مدعوماً بدليل تفاعلي مصور خطوة بخطوة لضبط نقطة الاتصال بأفضل أداء.
- **توجيه ذكي للاتصال:** تنبيهات وإرشادات فورية لضمان ارتباط الأجهزة على نفس الشبكة المحلية بسلاسة ودون تعقيد.

### 2. تكامل كامل مع نظام المشاركة في أندرويد | Native System Share Sheet Integration
- إمكانية مشاركة أي ملف أو وسائط مباشرة من داخل أي تطبيق آخر في الهاتف (المعرض، مدير الملفات، تطبيقات التواصل) عبر خيارين فوريين:
  - **مشاركة عبر الويب (Send4U Web):** يجهز الملفات فوراً للتحميل المباشر من أي متصفح على الكمبيوتر أو الآيفون.
  - **مشاركة عبر التطبيق (Send4U Direct):** يوجهك مباشرة لشاشة الرادار أو رمز الـ QR للإرسال الفوري لهاتف آخر.

### 3. استوديو الأدوات التفاعلية والمستندات ✨ | Interactive Whiteboard & Document Studio
- **سبورة تفاعلية حية (Live Collaborative Whiteboard):**
  - مساحة رسم وشرح فورية متزامنة بين الهواتف والمتصفح في الوقت الفعلي بزمن استجابة فائق السرعة (`120ms Delta Polling`).
  - دعم تصدير وحفظ الرسوميات والشروحات بدقة عالية بصيغ متعددة: **`PNG` ،`JPG` ،`WEBP` ،`PDF` ،`SVG`**.
- **دمج ملفات PDF (Merge PDFs):** دمج عدة مستندات PDF في ملف واحد منظم مع الحفاظ على الجودة الأصلية.
- **تحويل الصور إلى PDF (Images to PDF):** تجميع الصور وتحويلها إلى مستند PDF احترافي بضغطة واحدة.
- **تحويل PDF إلى Word (`.docx`):** استخراج وتحويل صفحات الـ PDF إلى مستندات Microsoft Word قابلة للتعديل ومتوافقة تماماً مع Word وGoogle Docs وWPS Office، سواء من داخل التطبيق أو عبر واجهة المتصفح.

### 4. إدارة ومشاركة التطبيقات المتقدمة | Smart App & Split APK Sharing
- **واجهة سريعة وخفيفة:** عرض منظم يركز على **أيقونة التطبيق، الاسم، والحجم الفعلي** لسرعة التصفح والاختيار.
- **دعم التطبيقات المثبتة (`Installed`):** استخراج ومشاركة أي تطبيق مثبت على الجهاز، مع دعم كامل للتطبيقات المقسمة والملفات التكميلية (Split APKs / OBB) وتغليفها تلقائياً كحزمة `.Send4U.zip` جاهزة للتثبيت.
- **دعم الحزم غير المثبتة (`Uninstalled APKs`):** فحص وعرض جميع ملفات `.apk` المخزنة على الجهاز لمشاركتها مباشرة دون الحاجة للبحث اليدوي في المجلدات.

### 5. بوابة الويب الشاملة (بدون تثبيت برامج) | All-in-One Zero-Install Web Portal
- بمجرد مسح رمز الـ QR أو فتح العنوان `http://<Phone-IP>:8080` على أي متصفح:
  - إرسال واستقبال الملفات والمجلدات الضخمة مباشرة بين الهاتف والكمبيوتر أو الآيفون.
  - غرفة محادثة فورية تدعم النصوص والرسائل الصوتية (Voice Notes) بين المتصفح والهاتف.
  - تحكم ثنائي الاتجاه في السبورة التفاعلية وأدوات معالجة وتحويل ملفات الـ PDF والـ Word مباشرة من شاشة الكمبيوتر.

### 6. معمارية تدفق مباشر وأمان متقدم | Zero-Cache Architecture & Enterprise-Grade Security
- **تدفق مباشر (Zero-Cache I/O):** كتابة وقراءة البيانات مباشرة على الذاكرة دون إنشاء نسخ مؤقتة تستهلك مساحة الجهاز، مع تنظيم تلقائي للملفات المستلمة لسهولة الوصول إليها.
- **تشفير محلي (AES-256 CTR):** تأمين كامل لحزم البيانات أثناء انتقالها عبر الشبكة المحلية.
- **استئناف تلقائي (Auto-Resume) وإدارة ذكية:** إكمال عمليات النقل المتوقفة من نفس النقطة عند انقطاع الاتصال، مع تنظيف ذاتي لأي بيانات مؤقتة غير مكتملة.
